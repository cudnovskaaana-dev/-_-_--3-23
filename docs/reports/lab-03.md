# Отчёт по лабораторной работе 

**Тема:** Vue: каркас и экраны
**Студент:** Чудновская Я.В. (группа ТРИС-3-23)

## 1. Цель работы
Поднять Vue 3 + Vite в папке `/frontend` и нарисовать три экрана: список заявок, создание заявки, вход. Сервер и база данных на этом этапе не используются.

## 2. Что было сделано
- Создан проект Vue 3 (JavaScript) в папке `/frontend`.
- Реализованы три экрана с переключением через `v-if`:
  - **Список** — таблица заявок на повреждение кабеля.
  - **Создать** — форма создания заявки.
  - **Вход** — форма логина и пароля (без реальной авторизации).
- В списке используется цикл `v-for` с ключом `:key="item.id"`, добавлены две тестовые записи со статусами `New` и `InProgress`.
- Форма создания содержит поля `title`, `siteId`, `description` (имена полей совпадают с ЛР2).
- Вся разметка использует семантические теги: `<main>`, `<form>`, `<label>`, `<table>`.
- Стили изолированы с помощью `<style scoped>`.

## 3. Вывод
Критерий 1 ЛР1 закрывают поля `title`, `siteId`, `description` на экране «Создать». Каркас запускается командой `npm run dev` на `http://localhost:5173`. Поля формы полностью совпадают с договором API из ЛР2. Работа выполнена.
