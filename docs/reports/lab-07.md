**Тема:** Каркас ASP.NET Core Web API  
**Студент:** Чудновская Я.В., ТРИС-3-23

## Цель

Подготовить backend для системы заявок и служебные адреса, необходимые для проверки запуска.

## Что подготовлено

- Проект ASP.NET Core находится в `backend/`.
- Настроен HTTP-профиль `http://localhost:5000`, Swagger в Development, адреса `/health` и `/info`.
- Созданы папки моделей, контроллеров, сервисов и данных. Интерфейс сервиса зарегистрирован через DI.
- README содержит команды запуска и пояснение назначения health-check.

## Проверка

Backend собран командой `dotnet build --no-restore` без предупреждений. Проверены `/health` и `/info`: оба ответили `200`; Swagger открылся по `/swagger` (редирект на `/swagger/index.html`).

## Вывод

Каркас задаёт адрес и разделение HTTP-контроллера и сервиса. `/health` сообщает только о доступности процесса, но не подтверждает сохранение заявок.
